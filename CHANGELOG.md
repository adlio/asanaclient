## [0.1.0] - 2026-02-08

### Added

- Initial release of the Asana API Rust SDK
- Tasks, projects, portfolios, sections, tags, stories, status updates, templates, users, workspaces
- Automatic pagination and strongly-typed responses
- Custom field support
- Events API module for incremental sync
- Configurable page size for paginated requests
